## Course-selection access

| Method | Entry point |
| --- | --- |
| Web | [Yanghua](https://yhxt.swjtu.edu.cn/) → 教务服务 → 网上选课 |
| WeChat | 西南交通大学 mini program → 本科生选课, during the announced availability window |

The notice requires checking the personal timetable after each selection round. PE and laboratory/practical courses use Yanghua; some PE and laboratory courses require a separate project or time selection.
