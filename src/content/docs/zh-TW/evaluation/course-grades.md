[2026—2027 學年第一學期選課通知](https://bksy.swjtu.edu.cn/info/1151/94201.htm)

## 選課入口

| 方式 | 入口 |
| --- | --- |
| 網頁 | [揚華學堂](https://yhxt.swjtu.edu.cn/) → 教務服務 → 網上選課 |
| 微信 | 「西南交通大學」小程式 →「本科生選課」；依學校通知的開放時段使用 |

通知要求每輪選課後檢查個人課表；體育、實驗實習類課程透過揚華學堂選擇，部分體育和實驗課程還需選擇項目或時間。

| --- | --- |

| 課程名額與開課安排 | 開課學院 |
| 選課系統 | 犀浦校區綜合樓 222；028-66366253、028-66367209 |
| 教務線上諮詢 | QQ 群 236830001（學校選課通知公布） |
