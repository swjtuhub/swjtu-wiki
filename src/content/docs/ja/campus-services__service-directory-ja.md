## 学習と手続き

| 用件 | 公式入口 | 案内・確認事項 |
| --- | --- | --- |
| オンライン手続きを探す | [一网通办](https://one.swjtu.edu.cn/) | [一卡通と WeCom](/ja/docs/campus-services/campus-card/) |
| 学部の通知・授業・証明 | [本科生院](https://bksy.swjtu.edu.cn/) | [教務手続き](/ja/docs/evaluation/academic-services/) |
| 大学院の課程・学位 | [研究生院](https://gsnews.swjtu.edu.cn/) | [教務手続き](/ja/docs/evaluation/academic-services/) |
| 学生支援・奨学助成・勤工助学 | [揚華素質網](https://xg.swjtu.edu.cn/) | [学生支援・グリーンチャンネル・緊急給付](/ja/docs/campus-services/student-aid/) |
| 求人・学内就職情報 | [就職情報サイト](https://jiuye.swjtu.edu.cn/) | 募集原文の職種・対象・締切を確認 |
| 国際交流 | [国際合作・交流処](https://fad.swjtu.edu.cn/) | 当期のプログラム条件を確認 |

部署と入口は[大学公式の機構一覧・リンク](https://www.swjtu.edu.cn/jgsz/xzbm.htm)で確認できます。奨学助成・勤工助学・交流は学期や募集回ごとの通知に従い、前年度の締切を流用しないでください。
