## メール登録とログイン

| 目的 | アクセス先・説明 |
| --- | --- |
| 学生メール | [学生メール](https://my.swjtu.edu.cn/)。アドレス末尾は `@my.swjtu.edu.cn` |
| 教職員メール | [教職員メール](https://home.swjtu.edu.cn/)。末尾は `@swjtu.edu.cn` |
| 個人メールの登録 | [信網処メール案内](https://inc.swjtu.edu.cn/wlfw/jdyx.htm)の「在线申请」からセルフ登録 |
| 登録の問い合わせ | [028-66366559](tel:02866366559)。案内上の窓口は犀浦図書館 B156 |

実名登録が必要で、個人は原則としてセルフ登録し、一人につき実名アカウント一つのみです。登録できない場合は案内に従って窓口申請の資料を用意してください。ログイン先は[大学公式サイト](https://www.swjtu.edu.cn/jgsz/xzbm.htm)からも確認できます。

## 交大クラウドストレージ

[公式案内](https://inc.swjtu.edu.cn/wlfw/jdyp.htm)の申請経路は「一网通办 → 交大云盘 → 个人云盘申请／部门云盘申请」です。

**学生の申請資格と容量は信網処に問い合わせてください。**
