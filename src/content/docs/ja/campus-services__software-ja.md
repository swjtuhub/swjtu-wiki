## インストール前の確認

1. 授業で必要なソフト名とバージョンを確認し、公式サイトの提供版と動作条件を確認します。
2. 現在の利用許諾範囲、アカウント条件、有効期限を読みます。リンクが残っていても、過去の提供条件・版・特典が現在も有効とは限りません。
3. ダウンロード・認証は公式手順に従います。Windows／Office の配布リンクだけでは Microsoft 365 クラウドサービスの利用権を確認できません。個人端末保護とサーバー EDR も別製品です。
4. 教育ライセンスに大学メールが必要な場合は[メール登録案内](/ja/docs/campus-services/email/)を参照してください。

導入・認証の問い合わせは一覧掲載の犀浦 [028-66366561](tel:02866366561)、九里 [028-87600223](tel:02887600223) へ。
