## Before installation

1. Check your course's software and version requirements, then verify available versions and operating-system requirements at the official source.
2. Read the current licence scope, account requirements and expiry terms. A link remaining in the directory does not guarantee that an old offer, version or licence term is still available.
3. Follow the platform's download and activation instructions. A Windows/Office download link does not establish Microsoft 365 cloud-service entitlement. Personal-device protection and server EDR are separate products.
4. If an education licence requires university email, see the [email guide](/en/docs/campus-services/email/).
