## 学内での通報・相談

[保衛処公式サイト](https://bwc.swjtu.edu.cn/)は次の **24 時間対応の学内通報・相談電話**を掲載しています。

| キャンパス | 電話 |
| --- | --- |
| 犀浦 | [028-66366110](tel:02866366110) |
| 九里 | [028-87600110](tel:02887600110) |

連絡時はキャンパス名、具体的な場所、状況、折り返し先を伝えてください。

## 保衛処の手続き

| 用件 | 公式サイトの中国語メニュー |
| --- | --- |
| 戸籍移転・戸籍資料・居住証 | 办事指南 → 户政业务 |
| 車両通行証・登録、外来者や車両の入構届出 | 办事指南 → 车辆业务 |
| 政審関連書類 | 办事指南 → 政审业务 |
| 学内の安全情報 | 安全警示 → 安全教育／警示案例 |

[保衛処トップページ](https://bwc.swjtu.edu.cn/)から各項目を開き、必要資料と条件を確認してください。2026 年新入生の戸籍登録案内は通知欄の **2026-09-03** から探せます。移転の要否や必要資料は全文で確認してください。

業務分類と通報電話は保衛処公式サイトに基づきます。一般の事務電話は 24 時間通報先ではありません。
