[2026—2027 学年第一学期选课通知](https://bksy.swjtu.edu.cn/info/1151/94201.htm)

## 选课入口

| 方式 | 入口 |
| --- | --- |
| 网页 | [扬华学堂](https://yhxt.swjtu.edu.cn/) → 教务服务 → 网上选课 |
| 微信 | “西南交通大学”小程序 → 本科生选课；按学校通知的开放时段使用 |

通知要求每轮选课后检查个人课表；体育、实验实习类课程通过扬华学堂选择，部分体育和实验课程还需选择项目或时间。

## 选课咨询

| 问题 | 联系方式 |
| --- | --- |
| 培养方案、修读要求 | 本学院教务老师 |
| 课程容量与开课安排 | 开课学院 |
| 选课系统咨询 | 犀浦校区综合楼 222；028-66366253、028-66367209 |
| 教务线上咨询 | QQ 群 236830001（学校选课通知公布） |
