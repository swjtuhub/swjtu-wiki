## 先確認需要哪一種帳號

| 要辦理的事 | 入口與說明 |
| --- | --- |
| 登入學校應用 | [交大 ID 統一身分認證](https://cas.swjtu.edu.cn/authserver/)；本科生與研究生編製學號後，系統據此自動開通認證帳號 |
| 開通校園網路 | [校園網帳號辦理說明](https://inc.swjtu.edu.cn/wlfw/xywzh.htm)；依說明完成預註冊、證件核驗及繳費 |
| 了解手機與寬頻整合方案 | [電信業者上網業務](https://inc.swjtu.edu.cn/wlfw/yysswyw.htm)；由業者計費 |
| 校外存取校內資源 | [交大 VPN](https://vpn.swjtu.edu.cn/)；使用交大 ID，不必另申請 VPN 帳號 |

帳號自動開通依據：[信網處統一認證說明](https://inc.swjtu.edu.cn/xxhfw/tysfrz.htm)。VPN 可用於校外存取圖書館文獻與限校內資源，實際範圍以系統服務為準，見[官方 VPN 說明](https://inc.swjtu.edu.cn/wlfw/VPNfw.htm)。

## 校園 Wi-Fi 與帳號辦理

公布的無線網路名稱為 `SWJTU-WiFi`，連線後使用校園帳號認證；無線接入本身不必另申請。[無線網路說明](https://inc.swjtu.edu.cn/wlfw/wxsw.htm)提供 Android、iOS 與電腦設定指南。該頁列舉犀浦、九里、峨眉的覆蓋區域，東部（國際）校區的連線方式須向當地服務窗口確認。

依[校園網帳號指南](https://inc.swjtu.edu.cn/wlfw/xywzh.htm)，新使用者先在[自助服務系統](http://service.swjtu.edu.cn/)預註冊，再攜學生證或一卡通及身分證到窗口正式開通。帳號名稱不要自行加上 `@cer` 或 `@wt`。帳號儲值也可在自助系統辦理。

> [!NOTE] 方案年份
> 業者頁面的資費表標註為「2025 年秋季」。辦理業務時請核對目前方案、合約期限與退訂條件，不要直接採用舊表或社群廣告價格。
