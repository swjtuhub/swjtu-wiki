## 校园报警求助

[保卫处官网](https://bwc.swjtu.edu.cn/)公布以下 **24 小时校园报警求助电话**：

| 校区 | 电话 |
| --- | --- |
| 犀浦 | [028-66366110](tel:02866366110) |
| 九里 | [028-87600110](tel:02887600110) |

联系时请说明所在校区、具体位置、发生的情况与可回拨号码。

## 保卫处办事入口

| 要办理的事 | 官网栏目 |
| --- | --- |
| 户口迁移、户籍材料、居住证相关业务 | 办事指南 → 户政业务 |
| 车辆通行证、车辆备案、外来人员及车辆入校报备 | 办事指南 → 车辆业务 |
| 政审相关材料 | 办事指南 → 政审业务 |
| 查看校园安全提醒 | 安全警示 → 安全教育／警示案例 |

从[保卫处首页](https://bwc.swjtu.edu.cn/)进入相应栏目，按具体事项核对材料及办理条件。2026 年新生入户须知可在首页通知公告中按 **2026-09-03** 查找；是否迁户及材料要求应阅读该通知全文。

上述办事目录与报警电话均来自保卫处首页；普通办公电话不能当作 24 小时报警电话。
