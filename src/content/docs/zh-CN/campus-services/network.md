## 先确认需要哪一种账号

| 要办理的事 | 入口与说明 |
| --- | --- |
| 登录学校应用 | [交大 ID 统一身份认证](https://cas.swjtu.edu.cn/authserver/)；本科生和研究生编制学号后，系统据此自动开通统一认证账号 |
| 开通校园网接入 | [校园网账号办理说明](https://inc.swjtu.edu.cn/wlfw/xywzh.htm)；按说明完成预注册、证件核验和缴费 |
| 了解手机与宽带融合套餐 | [运营商上网业务](https://inc.swjtu.edu.cn/wlfw/yysswyw.htm)；由运营商负责计费 |
| 校外访问校内资源 | [交大 VPN](https://vpn.swjtu.edu.cn/)；使用交大 ID，无需另行申请 VPN 账号 |

账号自动开通依据：[信网处统一身份认证说明](https://inc.swjtu.edu.cn/xxhfw/tysfrz.htm)。VPN 适用于校外访问图书馆文献及限校内访问的资源，具体访问范围以系统提供的服务为准，见[官方 VPN 说明](https://inc.swjtu.edu.cn/wlfw/VPNfw.htm)。

## 校园 Wi-Fi 与账号办理

信网处公布的无线网络名称为 `SWJTU-WiFi`，接入后使用校园账号认证；无线接入本身无需另行申请。[无线网络说明](https://inc.swjtu.edu.cn/wlfw/wxsw.htm)提供 Android、iOS 和电脑配置指南。该页列举犀浦、九里、峨眉的覆盖区域，东部（国际）校区的接入方式应向本校区服务窗口确认。

按[校园网账号指南](https://inc.swjtu.edu.cn/wlfw/xywzh.htm)，新用户先在[用户自助服务系统](http://service.swjtu.edu.cn/)预注册，再携带学生证或一卡通及身份证到前台正式开通。用户名不要自行添加 `@cer` 或 `@wt` 后缀。账号充值也可在自助服务系统中办理。

> [!NOTE] 套餐年份
> 信网处运营商页面的资费表标注为“2025 年秋季”。办理业务时，请核对当前套餐、合约期限和退订条件，不要直接按旧表或社交平台广告中的价格办理。
