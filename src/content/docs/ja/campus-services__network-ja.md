## 必要なアカウントを確認する

| 目的 | アクセス先・説明 |
| --- | --- |
| 大学のアプリにログイン | [交大 ID 統一認証](https://cas.swjtu.edu.cn/authserver/)。学部生・大学院生は学籍番号の発行後に認証アカウントが自動作成されます |
| 学内インターネットの利用開始 | [ネットワークアカウント案内](https://inc.swjtu.edu.cn/wlfw/xywzh.htm)に従い、仮登録・本人確認・支払いを行います |
| 携帯電話とブロードバンドのセット契約 | [通信事業者のサービス](https://inc.swjtu.edu.cn/wlfw/yysswyw.htm)。料金は事業者が管理します |
| 学外から学内資料へアクセス | [交大 VPN](https://vpn.swjtu.edu.cn/)に交大 ID でログイン。別の VPN アカウント申請は不要です |

自動作成については[統一認証の説明](https://inc.swjtu.edu.cn/xxhfw/tysfrz.htm)、学外からの文献・学内限定資料の利用範囲については[VPN 案内](https://inc.swjtu.edu.cn/wlfw/VPNfw.htm)を参照してください。利用できる資料はシステムの提供範囲によります。

## Wi-Fi と利用開始手続き

公表されている SSID は `SWJTU-WiFi` です。接続後に学内アカウントで認証し、無線接続自体の別途申請は不要です。[無線ネットワーク案内](https://inc.swjtu.edu.cn/wlfw/wxsw.htm)には Android・iOS・パソコンの設定方法があります。同ページの対象は犀浦・九里・峨眉で、東部（国際）の接続方法は現地窓口に確認してください。

[アカウント案内](https://inc.swjtu.edu.cn/wlfw/xywzh.htm)では、[セルフサービスシステム](http://service.swjtu.edu.cn/)で仮登録し、学生証またはキャンパスカードと身分証明書を持って窓口で本登録する手順を示しています。ユーザー名に `@cer` や `@wt` を自分で付けないでください。残高のチャージも同システムで行えます。

> [!NOTE] 料金表の年度
> 通信事業者ページの料金表は「2025 年秋季」と表示されています。申込時に現在の料金・契約期間・解約条件を確認し、旧料金表や SNS 広告だけで判断しないでください。
