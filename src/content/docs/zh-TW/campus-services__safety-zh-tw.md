## 校園報警求助

[保衛處官網](https://bwc.swjtu.edu.cn/)公布以下 **24 小時校園報警求助電話**：

| 校區 | 電話 |
| --- | --- |
| 犀浦 | [028-66366110](tel:02866366110) |
| 九里 | [028-87600110](tel:02887600110) |

聯絡時說明校區、具體位置、事件與回撥號碼。

## 保衛處辦事入口

| 要辦理的事 | 官網欄目 |
| --- | --- |
| 戶口遷移、戶籍資料、居住證 | 辦事指南 → 戶政業務 |
| 車輛通行證、備案、外來人員與車輛入校報備 | 辦事指南 → 車輛業務 |
| 政治審查（政審）資料 | 辦事指南 → 政審業務 |
| 校園安全提醒 | 安全警示 → 安全教育／警示案例 |

由[保衛處首頁](https://bwc.swjtu.edu.cn/)進入對應欄目，依事項核對資料和條件。2026 年新生入戶須知可在通知公告按 **2026-09-03** 查找；是否遷戶與資料要求須閱讀全文。

目錄與電話均來自保衛處首頁；一般辦公電話並非 24 小時報警電話。
