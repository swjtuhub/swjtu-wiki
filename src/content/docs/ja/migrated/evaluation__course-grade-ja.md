[2026–2027 学年度第 1 学期の履修登録通知](https://bksy.swjtu.edu.cn/info/1151/94201.htm)

## 履修登録システム

| 方法 | アクセス先 |
| --- | --- |
| Web | [揚華学堂](https://yhxt.swjtu.edu.cn/) → 教务服务 → 网上选课 |
| WeChat | 「西南交通大学」ミニプログラム → 本科生选课。大学が案内する利用可能時間内に操作 |

通知では、各登録期間後に個人時間割を確認するよう求めています。体育・実験実習科目は揚華学堂で登録し、一部の体育・実験科目では種目や時間の選択も必要です。

## 履修登録の問い合わせ

| 相談内容 | 窓口 |
| --- | --- |
| 教育課程・履修要件 | 所属学部の教務担当 |
| 履修定員・開講予定 | 開講する学部 |
| 登録システム | 犀浦キャンパス総合楼 222 室；028-66366253 / 028-66367209 |
| オンライン教務相談 | QQ グループ 236830001（大学の登録通知に掲載） |
