## 本科生：按事项找办事指南

[教学服务网上办事平台](https://jiaowu.swjtu.edu.cn/vatuu/WebSite?setAction=index)的“学生”栏目列有下列事项。先打开对应指南确认对象、材料与申请时间，再进入申请系统。

| 需求 | 在平台中查找 |
| --- | --- |
| 成绩与在读材料 | 成绩单打印、学籍（在读）证明 |
| 对课程成绩有疑问 | 成绩复议申请 |
| 课程安排发生冲突或需要处理考试事项 | 冲突选课、缓考申请、补考报名 |
| 证件遗失 | 学生证补办、火车票优惠卡补办 |
| 查询学习要求与课表 | 信息查询中的培养方案、课程大纲、本学期课程安排、期末考试安排 |

毕业生／校友另有独立栏目，不应默认与在校生使用同一办理流程。页面列出业务入口也不代表该业务全年开放；选课和考试仍须核对[本科生院当期通知](https://bksy.swjtu.edu.cn/)及学院要求。

### 本科生在读证明

[学籍（在读）证明办理页](https://jiaowu.swjtu.edu.cn/vatuu/WebSite?setAction=detail&tspId=8E3746FC429F906F&tspSortId=61E92EF67418DC54)列出的纸质办理步骤为：先在线选择打印份数并完成支付，申请成功后登录自助打印机，选择该申请打印；**一个申请只能打印一次**。

| 校区 | 自助打印机位置 |
| --- | --- |
| 犀浦 | 综合楼 2 楼教务处旁；学生服务大厅（犀浦 2 教） |
| 九里 | 逸夫馆 1 楼正门入口大厅右侧 |

咨询电话：教务科 [028-66366252](tel:02866366252)。电子证明请从页面中的“可信电子证明申请”入口查看办理说明。

## 研究生：成绩证明与培养材料

研究生院提供[在读证明、中英文成绩单的可信电子证明操作指南](https://gsnews.swjtu.edu.cn/info/1957/24034.htm)。页面发布于 2023-04-06，当前附件名标注 **2024-11-22 更新**，应从页面获取该附件，不使用更早的流程截图。

[研究生院“下载中心 → 培养工作”](https://gsnews.swjtu.edu.cn/xzzx/pygz.htm)还提供研究生管理信息系统指南及硕博培养环节材料。部分条目的列表日期较早，但附件或标题另有更新日期，下载时应同时检查。
